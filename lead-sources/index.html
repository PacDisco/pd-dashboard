Setup: getting the real source into HubSpot
  1. Create the contact properties the quiz and application write to (pd_first_*, pd_last_*, pd_quiz_*) —
  2. HubSpot forms: in Quiz → Settings & HubSpot and Apply Form → Fee, interview & text, click Create in HubSpot (or paste a form ID), then Publish. From then on HubSpot's own Original Source is right for new leads.
  3. Track first visits on the main website. Add this to every page of www.pacificdiscovery.org (e.g. the WordPress footer), so a visitor who lands from an ad, then browses, then takes the quiz days later is still credited to the ad: 
    <script src="https://apply.pacificdiscovery.org/attribution.js" async></script>
  4. Turn off the old Zaps / Make scenarios that create HubSpot contacts from the Jotform quiz and step 1 — they create contacts before the form can, which is what makes them “Offline”.
